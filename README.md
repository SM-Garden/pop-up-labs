# Group Order in cafe
카페에서 많은 인원이 단체로 주문을 해야 할 경우, 접수와 주문 그리고 배포까지 손쉽게 할 수 있도록 돕는 생활용 웹앱.
직장 내에서 똘똘하고 사랑받는 직원이 될 수 있다.
